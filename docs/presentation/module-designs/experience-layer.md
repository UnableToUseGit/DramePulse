# 体验层模块设计

## 1. 模块定位

体验层面向用户，负责把后端下发的内容、弹幕和互动方案渲染成移动端短剧观看体验。

体验层不负责识别高光点，不负责生成互动方案，也不负责长期存储业务数据。

## 2. 子模块

### 2.1 短剧播放器

负责短剧列表、竖屏播放、播放/暂停、进度控制、上下滑切换和当前播放时间监听。

### 2.2 普通弹幕层

负责展示从后端或样例数据读取的普通弹幕，并在移动端进行采样、节流和轨道调度。

### 2.3 即时互动组件

负责在 `Interaction Plan.trigger_time` 到达时展示弹幕投票。用户点击选项后，组件展示比例反馈，并在短暂停留后自动消失。

### 2.4 用户行为采集

负责采集互动曝光、选项点击、反馈展示、自然消失、播放暂停和 seek 等事件，并上报后端。

## 3. 输入输出

输入：

- 视频元数据；
- 视频播放地址；
- 普通弹幕；
- 互动方案；
- 当前播放时间。

输出：

- 播放行为事件；
- 互动曝光事件；
- 互动点击事件；
- 反馈展示事件；
- 互动关闭或自然消失事件。

## 4. 当前实现草稿
