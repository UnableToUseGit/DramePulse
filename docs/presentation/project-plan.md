# 分工与开发时间线

## 1. 文档目的

本文档用于比赛最终交付，说明 DramePulse 的工作项拆分、开发排期、角色分工模板和 AI 辅助参与环节。

当前先使用角色分工模板，后续根据实际团队成员姓名补充。

## 2. 工作项拆分

| 工作项 | 内容 | 产出 |
| --- | --- | --- |
| 产品设计 | 赛题理解、用户痛点、MVP 范围、交互方案 | 产品 PRD、演示脚本 |
| 系统设计 | 三层架构、核心对象、技术选型、系统流程 | 系统设计文档、流程图 |
| 前端播放器 | 短剧列表、竖屏播放、弹幕、即时互动、事件采集 | Expo 播放器 Demo |
| 后端 API | 视频、弹幕、互动方案、事件、统计、Story Q&A 接口 | FastAPI 服务 |
| 算法 pipeline | 高光点识别、互动方案生成、结构化校验 | Highlight Asset、Interaction Plan |
| 数据与标注 | 样例数据整理、弹幕处理、人工标注、契约维护 | 数据集、标注结果、JSON Schema |
| 部署与演示 | 云端 API、本地服务、演示录屏、答辩材料 | 可访问服务、展示录屏 |
| 测试与验证 | 类型检查、接口 smoke check、播放链路验证 | 验证记录 |

## 3. 开发时间线

| 阶段 | 时间 | 目标 |
| --- | --- | --- |
| 赛题理解与方案设计 | 第 1 阶段 | 明确产品方向、MVP 闭环和技术架构 |
| 基础工程搭建 | 第 2 阶段 | 完成播放器、后端、数据契约和样例数据基础 |
| 核心链路开发 | 第 3 阶段 | 打通高光识别、互动方案生成、播放器触发和事件上报 |
| 演示能力增强 | 第 4 阶段 | 优化播放器体验、弹幕展示、互动反馈和 Story Q&A |
| 部署与文档交付 | 第 5 阶段 | 完成云端部署、最终文档、录屏和答辩材料 |

## 5. AI 辅助说明

本项目允许并鼓励使用 AI 辅助。DramePulse 中 AI 主要参与以下环节：

- 产品和技术文档初稿整理；
- 高光点识别中的字幕和视频帧理解；
- 互动方案生成中的问题和选项文案生成；
- 代码开发中的实现建议、调试和测试辅助；
- 答辩材料中的结构梳理和表达优化。

AI 生成内容不会直接无校验进入生产链路。高光资产、互动方案和文档内容都需要经过规则校验、人工检查或演示验证。
