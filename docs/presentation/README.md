# DramePulse 最终交付文档

本目录存放 DramePulse 比赛最终交付用技术文档。文档面向评委、答辩听众和项目协作者，目标是说明产品问题、系统设计、模块实现、项目计划和 AI 辅助情况。

建议阅读顺序：

1. [产品 PRD](./product-prd.md)
2. [系统设计](./system-design.md)
3. [体验层模块设计](./module-designs/experience-layer.md)
4. [业务层模块设计](./module-designs/business-layer.md)
5. [数据层模块设计](./module-designs/data-layer.md)
6. [API 契约设计](./module-designs/api-contracts.md)
7. [分工与开发时间线](./project-plan.md)

## 文档分工

- `product-prd.md`：讲清楚为什么做 DramePulse、用户痛点、MVP 范围和产品验收标准。
- `system-design.md`：从系统层面讲清楚整体架构、三层交互、技术选型和端到端闭环。
- `module-designs/`：按 layer 拆解具体模块，补充系统设计中不展开的实现细节。
- `project-plan.md`：说明工作项拆分、开发排期、角色分工模板和 AI 辅助环节。

## 当前状态

当前文档结构已经搭建完成，部分文件仍是草稿。后续会基于仓库已有工程文档、代码实现和演示链路逐步补全。
